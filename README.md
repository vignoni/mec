# LEGO EV3 PID Controller Grader

This repository uses GitHub Actions to automatically evaluate student `.csv` submissions for Practice 5 of the Mechatronics course.

## 📤 How to Submit

1. Fork this repository.
2. Add your CSV file with name format: `yourname.csv`.
3. Push to your fork — the grading will run automatically and appear below.
